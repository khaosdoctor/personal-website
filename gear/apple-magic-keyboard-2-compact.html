Description

This is my oldest keyboard, I think. I got it somewhere around 2017, when I bought my second MacBook after the first one got stolen, and it has been quite useful because it's very small, the battery lasts quite a long time and it is very comfortable. Right now it's sitting at my parents' house, because I usually use it when I come back to Brazil.

Impressions

The impressions for this Magic Keyboard are the same as for every Magic Keyboard. It looks nice, it is sturdy, it types well, and I don't know how the new ones are, but this one is pretty good. The battery lasts more than a month.

The Lightning port is a big issue because it's Lightning and we don't really use that anymore, so I think the new ones are USB-C. But I stopped using it because I wanted to have a mechanical keyboard. I really think mechanical keyboards are way better to type on than these keyboards, because this one is a low profile keyboard and I really don't like low profile keyboards.
