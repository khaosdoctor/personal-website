Brazilian software engineer in Stockholm since 2021, Staff Engineer at Hemnet.

I've been messing with computers since I was 5 and writing software since 2012. Mostly backend and architecture these days, plus some Node.js core contributions, but I'll happily poke at any part of the stack, and I have a lot of love for open source.

I like sharing what I learn, so I wrote a book (soon books), courses on my own and for companies, and a blog. That got me Microsoft MVP, Google Developer Expert and Docker Captain for many years.

Mostly, I really like to build stuff. LEGOs, a homelab slowly turning into a personal cloud, a 3D printer that never stops, an electronics workbench in progress, and whatever else I can get my hands dirty with. If I can build instead of buy, I will. Not because it's easier, but because it's harder (and often more expensive).

Off the computer, I'm a huge cat guy and love music. I play guitar and bass, but mostly I build gear for them, pedals, cables and completely useless but super cool gimmicks.
