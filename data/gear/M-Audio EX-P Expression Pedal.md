## Description

An expression pedal I use mostly with Logic, to control things like volume or a wah sweep with my foot. I tried to get it working with the Positive Grid Spark, but no luck.

I bought it because controlling things while I'm in Logic, or in AmpliTube, or anything in between, is very annoying. AmpliTube from IK Multimedia especially has a very bad interface, so both this expression pedal and the [[M-VAVE Chocolate MIDI Controller|MIDI controller]] I got were specifically so I could control things inside AmpliTube without having to use the interface.

## Impressions

I use the expression pedal mostly for volume, so I tie it to a volume pedal that I put in the signal chain. I've used it very little though. I mostly use it when I'm recording, and lately I haven't been recording much, so I've used it four or five times.

It's a good pedal. The problem is that the software is horrible, you can't control absolutely anything with it, it's terrible. Luckily the pedal doesn't need the software that much. It does have a strange thing, which is a mode that inverts what it normally does, so when you go back it actually increases and when you press the pedal down it actually decreases. It has two modes, so you have to switch between them, and that makes it a bit strange to use.

In general it's well built and it's a super cheap pedal, so for the price it's very good. The usability is a bit difficult though, there's some learning to do there.

## Final thoughts

It works with MIDI controllers from the same brand, and I haven't tested it with much else. On the [[Positive Grid Spark 40|Spark]] it never worked, and from what I understood the Spark has its own thing going on, which is probably why.

Basically I use it because VST interfaces are very bad.
